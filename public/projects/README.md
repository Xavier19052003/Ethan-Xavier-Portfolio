# Project screenshots

Add approved screenshots here (prefer WebP, around 1400px wide, optimised for web).
Set `image` in `src/data/projects.ts` to `projects/your-image.webp` and provide descriptive `imageAlt`. Paths are relative to the public directory with no leading slash. Add extra images to `gallery` with `src` and `alt`.

Until then the website uses explicitly labelled, original typographic cover placeholders, not fabricated project screenshots. EduSwap has three labelled gallery slots to replace with real application screenshots. Only use screenshots you have permission to publish and that accurately reflect your contribution.
