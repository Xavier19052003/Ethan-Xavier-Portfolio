# CV location

The current professional CV is integrated at `public/Ethan_Xavier_Peters_CV.pdf`, configured by `profile.cvFile`. Replace that file to update every CV button. The original Downloads file is untouched.

## Alternate folder configuration

Place your real PDF here, named exactly `Ethan_Xavier_Peters_CV.pdf`.
All CV buttons automatically enable after the site successfully loads and verifies the PDF header. Missing files and HTML fallback responses keep the buttons disabled. No code change is required. Rebuild and redeploy after adding or replacing the file.

The filename is configurable in `src/data/profile.ts`. Do not commit confidential information you do not want publicly downloadable.
